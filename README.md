# RePacks - Minecraft Bedrock Content Manager

A simple and modern content manager for **Minecraft Bedrock Edition on Windows**. Easily install addons, packs, and export your worlds.

## Features
* **Addon Installer:** Quickly install Minecraft Bedrock addons and texture packs.
* **World Exporter:** Easily export and backup your game worlds.
* **Modern Interface:** Clean and fast UI built specifically for Windows.

## Installation & Usage
1. Download the latest release from the sidebar.
2. Run the application and manage your Minecraft Bedrock content effortlessly.
