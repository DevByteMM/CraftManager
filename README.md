CraftManager - Minecraft Bedrock Content Manager

A simple and modern content manager for Minecraft Bedrock Edition on Windows.
Easily manage your addons, resource packs, behavior packs, and worlds in one place, and download any packs worlds .......

Features

* Addon Manager: Quickly install and manage Minecraft Bedrock addons, resource packs, and behavior packs.
* World Manager: Easily export, backup, and manage your Minecraft Bedrock worlds.
* Automatic Detection: Automatically detects your Minecraft Bedrock content folders.
* A clean, fast, and user-friendly interface built specifically for Windows.
* online mods hub: download any mods or packs or maps you want

Installation & Usage

1. Download the latest release from the Releases section.
2. Run CraftManager.exe.
3. Manage your Minecraft Bedrock content effortlessly.


Supported Content

* Addons (.mcaddon)
* Resource Packs (.mcpack)
* Behavior Packs
* Minecraft Worlds (.mcworld)
* skin packs

CraftManager makes managing Minecraft Bedrock content simple, fast, and organized.
